Ambiente para testes de automação

Ambiente de testes controlado. Este site (https://fluxo-automacao.9eivnx.easypanel.host/) é uma aplicação de demonstração mantida por Pedro Hilário para testes de automação.

Permitido neste domínio: criar, editar e excluir contas de teste em volume, usar proxies, bots e ferramentas de automação (Playwright, Selenium e agentes de IA).

Fora do escopo: esta autorização vale exclusivamente para este domínio. Ela não se aplica a nenhum outro site ou serviço.

Dados fictícios: as contas podem ser apagadas a qualquer momento.
